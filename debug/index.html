Try a real application

Start Fish, then paste this to distinguish its Vi modes:

fish_vi_key_bindings
set -g fish_cursor_default block
set -g fish_cursor_insert line
set -g fish_cursor_visual underscore

Or run nvim -u NONE -i NONE -n and configure its modes:

:set guicursor=n-c:block-blinkon0,i:ver25-blinkon0,v:hor20-blinkon0

Type text, then switch with Escape, i, and v. Neovim normally uses the same block in normal and visual modes.
